# shahbaz

Automatically maintained list of public SSTP endpoints.

- `data/vpngate.json` – hourly snapshot of the public VPN Gate list (compact).
- `results/*.json` – reachability results from independent probes.
- `data/list.json` – merged, ranked list; `data/list.json.sig` – Ed25519 signature (base64) over the exact bytes of `list.json`; `data/public_key.txt` – verification key (base64).

Data is generated by GitHub Actions; no manual edits.
